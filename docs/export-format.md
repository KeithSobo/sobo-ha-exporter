# Reference Export Specification

This document describes the structure and format of exported files generated by `sobo-ha-exporter`.

## Configuration Path

The default Home Assistant configuration directory read by the exporter inside the container is `/homeassistant` (mapped via Home Assistant OS `homeassistant_config`). It can be customized via the `CONFIG_DIR` environment variable.

## Inventory Outputs (`inventory/`)

- **`inventory/entities.json`**: List of normalized entity records sorted by `entity_id`.
- **`inventory/devices.json`**: List of normalized device records sorted by name. Each device includes a sorted, deduplicated `entities` array listing associated entity IDs.
- **`inventory/areas.json`**: Area definitions sorted by name.
- **`inventory/labels.json`**: Label definitions sorted by name.
- **`inventory/integrations.json`**: Active integrations derived from entity platforms and device integration domains.
- **`inventory/relationships.json`**: Multi-directional mapping matrices.

## Reference Maps (`references/`)

- **`references/automation-entity-map.json`**: Association between automations and referenced entities.
- **`references/device-entity-map.json`**: Association between devices and member entities.
- **`references/area-device-map.json`**: Devices associated with each area.
- **`references/label-target-map.json`**: Entities and devices tagged per label.
- **`references/entity-usage.json`**: Inverted index of entity references.

## AI Reference Layer (`ai/`)

Compact, deterministic, navigable reference outputs designed for AI context ingestion (ChatGPT, Antigravity, etc.):

- **`ai/README.md`**: Guide for AI tools on navigating the reference layer.
- **`ai/overview.md`**: Installation totals, metadata, and navigation links.
- **`ai/areas.md`**: Per-area breakdown of devices, entities, automations, and integrations.
- **`ai/devices-by-area.md`**: Devices grouped under effective areas (including Unassigned).
- **`ai/entities-by-domain.md`**: Domain-level entity summaries with counts and device classes.
- **`ai/helpers.md`**: Classified Home Assistant helper entities (input_*, counter, timer, schedule, group, template).
- **`ai/automations.md`**: Detailed automation triggers, conditions, actions, service calls, and reverse usage statistics.
- **`ai/scripts.md`**: Detailed script steps, service calls, and referenced entities.
- **`ai/integrations.md`**: Domain-level integration stats derived from entity platforms.
- **`ai/labels.md`**: Label usage breakdowns.
- **`ai/dashboards.md`**: Dashboard analysis overview or status statement.
- **`ai/orphaned-and-unassigned.md`**: Breakdown of unassigned, area-less, device-less, or unreferenced records.
- **`ai/impact-index.json`**: Reverse-dependency index mapping entities, devices, and areas to automations, scripts, and dashboards.
- **`ai/search-index.json`**: Search records with normalized keyword arrays for AI context retrieval.

### AI Configuration Summaries (`ai/configuration/`)

Generated when `export.configuration_summary: true` (default):

- **`ai/configuration/README.md`**: Explanation of generated summaries vs raw backups.
- **`ai/configuration/overview.md`**: Analyzed file counts, warnings, node counts, integration flags.
- **`ai/configuration/home-assistant.md`**: Top-level domain analysis and sensitive section status (`configured` / `redacted` / `secret reference`).
- **`ai/configuration/esphome.md`**: ESPHome node features, platform/board, components, pins, and auth status (zero real secret values).
- **`ai/configuration/packages.md`**: Discovered package files and domains.
- **`ai/configuration/automations.md`**: Automation structural counts and summaries.
- **`ai/configuration/scripts.md`**: Script structural summaries.
- **`ai/configuration/scenes.md`**: Scene structural summaries.
- **`ai/configuration/dashboards.md`**: UI and YAML dashboard counts.
- **`ai/configuration/mqtt.md`**: MQTT broker source, discovery, TLS, and auth status (no broker credentials).
- **`ai/configuration/frigate.md`**: Frigate NVR cameras, detectors, recording, go2rtc status (no RTSP credentials).
- **`ai/configuration/zigbee2mqtt.md`**: Zigbee2MQTT frontend and MQTT status (no network keys).
- **`ai/configuration/custom-components.md`**: Custom component metadata and manifests.
- **`ai/configuration/warnings.md`**: Consolidated analysis warnings.

## Raw Configuration Export (`config/`)

Generated ONLY when `advanced.raw_configuration_export: true` (disabled by default):

- Contains sanitized raw YAML configuration files.
- Excludes `secrets.yaml`, `.storage`, databases, logs, backups, certificates, and private keys.
- Secret-scanned prior to publication; publication is blocked if unhandled secrets remain.

## Markdown Summaries (`summaries/`)

- **`summaries/entity-summary.md`**
- **`summaries/device-summary.md`**
- **`summaries/integration-summary.md`**
- **`summaries/area-summary.md`**

## Metadata Output (`metadata/`)

- **`metadata/export-info.json`**: Run timestamp and export statistics.
- **`metadata/exporter-version.json`**: Add-on version details.
- **`metadata/sanitization-report.json`**: Summary of redacted categories.
- **`metadata/warnings.json`**: Non-fatal warnings encountered during collection or parsing.
